How I work

  1. Ask a real questionAbout Morocco, with open data that anyone can check.
  2. Test it fairlyCompare against fair baselines, and report p-values, even when they say "could be chance".
  3. Correct the storyWhen the full data disagrees with a first result, the first result goes.
  4. Show the methodEvery number comes from code that's public on GitHub.
